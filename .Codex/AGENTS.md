# BRISKER project context

This repository contains the static public website for BRISKER.

## Deployment

- GitHub repository: `justvisiting/brisker`
- GitHub Pages source: `main` branch, repository root
- Custom domain: `brisker.in`
- Do not modify the separate default `justvisiting` Pages repository or its `matrion.in` mapping.

## Site files

- `index.html` is the complete one-page site.
- `hero.png` is the hero image referenced by `index.html`.
- `CNAME` must remain `brisker.in` for GitHub Pages.
